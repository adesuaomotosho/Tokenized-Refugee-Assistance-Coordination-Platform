# Tokenized Refugee Assistance Coordination Platform

A blockchain-based platform built on Stacks that coordinates refugee assistance through smart contracts, ensuring transparent and efficient aid distribution.

## Overview

This platform consists of five interconnected smart contracts that manage different aspects of refugee assistance:

1. **Identity Verification Contract** - Establishes refugee documentation and status
2. **Resource Allocation Contract** - Distributes aid supplies and services
3. **Resettlement Matching Contract** - Connects refugees with host communities
4. **Skill Assessment Contract** - Evaluates professional capabilities for employment
5. **Integration Support Contract** - Provides language and cultural adaptation assistance

## Features

### Identity Verification
- Secure refugee identity registration
- Document verification and status tracking
- Privacy-preserving identity management
- Status updates and verification history

### Resource Allocation
- Transparent aid distribution tracking
- Resource inventory management
- Priority-based allocation system
- Distribution history and analytics

### Resettlement Matching
- Host community registration
- Refugee-host matching algorithm
- Capacity and preference management
- Successful placement tracking

### Skill Assessment
- Professional skill documentation
- Certification and credential tracking
- Employment readiness scoring
- Skills-based job matching preparation

### Integration Support
- Language learning progress tracking
- Cultural adaptation milestone system
- Support service coordination
- Integration success metrics

## Smart Contract Architecture

Each contract operates independently to ensure modularity and security:

- \`identity-verification.clar\` - Core identity and status management
- \`resource-allocation.clar\` - Aid distribution and inventory
- \`resettlement-matching.clar\` - Host-refugee matching system
- \`skill-assessment.clar\` - Professional capability evaluation
- \`integration-support.clar\` - Cultural and language adaptation

## Getting Started

### Prerequisites
- Stacks blockchain development environment
- Clarity smart contract compiler
- Node.js for testing

### Installation

1. Clone the repository
2. Install dependencies: \`npm install\`
3. Run tests: \`npm test\`
4. Deploy contracts to Stacks testnet

### Testing

The platform includes comprehensive test suites using Vitest:

\`\`\`bash
npm test

## Usage

### For Refugees
1. Register identity through the identity verification contract
2. Complete skill assessments for employment preparation
3. Access allocated resources based on verified needs
4. Participate in resettlement matching process
5. Track integration progress and access support services

### For Aid Organizations
1. Register as resource providers
2. Allocate resources through the distribution system
3. Monitor aid distribution effectiveness
4. Access analytics and reporting

### For Host Communities
1. Register hosting capacity and preferences
2. Participate in refugee matching process
3. Provide integration support services
4. Track successful placements
